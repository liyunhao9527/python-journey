类型用途与写法边界
list 列表按顺序保存可增删的数据：[first, second]索引从 0 开始，越界报 IndexError；[-1] 取末项，空列表仍会报错。
dict 字典按键保存字段：{"topic": "容器", "minutes": 30}用 ["topic"] 读取；缺键报 KeyError。Python 3.7+ 保留插入顺序，整数键不表示字段位置。
tuple 元组固定位置的组合：("容器", 30)不能增删或替换元素；内层可变对象仍能修改。单元素需要逗号。
set 集合去重、判断成员：set(["容器", "容器"])不保证顺序，不能按位置索引。空集合 set()；{} 是空字典。

dict 的键与 set 的元素必须可哈希，即哈希值稳定且符合相等性规则。字符串与整数可用，list 与 dict 不可用；不要用 set(records) 给字典记录去重。

读取、修改与复制

append 在原列表末尾追加一个元素，返回 None；get 在键不存在时返回指定的默认值，不写入字典；copy 创建外层容器的浅复制。

records = [{"topic": "容器", "minutes": 30}]
records.append({"topic": "字符串", "minutes": 25})
print(len(records))                  # 2
print(records[0]["minutes"])         # 30
print("note" in records[0])          # False：查键
print(records[0].get("note", "未填写"))

draft = records.copy()              # 新列表，内部字典仍共享
draft[0] = draft[0].copy()           # 再复制第一条字典
draft[0]["minutes"] = 40
print(records[0]["minutes"])         # 30

copy 只复制一层。本例记录只有字符串、整数值，可以独立替换字段；若字段里还有列表，那一层仍共享。get 遇到已存在且值为 None 的键，返回 None。

TS / Python 对照边界

下面按同一个“保存学习记录”的任务对照；完整平行代码见第四课。

目标差异与边界取舍
追加一条记录list.append 返回 None；Array.push 返回新长度。只需修改列表时无明显优劣；不要把 append 结果赋回列表名字。
复制记录列表list.copy() 与 [...array] 都只复制外层。增删外层方便，修改内部记录仍需另行复制；本例无明显优劣。
读取可选备注dict.get 可提供缺键默认值；JS 可先用 Object.hasOwn 判断自有字段是否存在。TS 类型可提前指出未声明字段，Python [] 缺键在运行时报错。Python 动态字段简便，TS 明确结构利于静态检查；两者都需区分缺失与已有空值。
固定主题、分钟组合tuple 在运行时限制结构；TS readonly 元组只约束静态检查。两者都不保证内层对象不可变。Python 直接限制替换位置，TS 能声明位置类型；字段多时用具名字段更易读。
对字符串主题去重Python set 不保证顺序，JS Set 保留插入顺序。JS 可存对象并按身份区分；Python dict 不可作为 set 元素。统计不同主题数无明显优劣；Python 如需保留原顺序，应保留列表。
