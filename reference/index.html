安装 uv 与 Python

先按 uv 官方安装指南安装 uv，再执行下面的命令。若希望自己下载安装 Python，可访问 Python 官网选择适合自己电脑的安装包。 

uv --version
uv python install 3.14
uv python list --only-installed

固定项目版本与同步环境

在包含 pyproject.toml 的项目根目录执行。版本写入 .python-version，环境位于 .venv。 

uv python pin 3.14
uv sync
uv run python --version
uv run python -c "import sys; print(sys.executable)"

单纯进入目录不会自动切换终端中的 python；使用 uv run 选择项目环境。

运行第一课

第一次输出问候与学习时间；第二次输出计时练习的参考结果。

uv run python demos/01-hello/main.py
uv run python demos/01-hello/solution.py

后续课管理依赖

学到测试时再执行。这些命令会将 pytest 加入开发依赖并更新锁文件；第一课不需要安装它。 

uv add --dev pytest
uv run pytest

添加运行依赖使用 uv add 包名，移除时使用 uv remove 包名。依赖声明在 pyproject.toml 中，解析结果记录在 uv.lock 中。
