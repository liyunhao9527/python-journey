变量与对象速查。

先区分重新绑定、修改内容与比较对象。

四条规则

  • 赋值绑定名字，不自动复制对象。
  • int、float、bool、str 不可变；list 可原地修改。
  • == 判断相等，is 判断身份；缺失值通常用 is None。
  • type(x) 查看类型；int("25") 将合法整数文本转换为整数。
a = [25]
b = a
b.append(5)  # a 也能看到 [25, 5]
b = [5]     # 只重新绑定 b，a 仍是 [25, 5]

Python 列表 == 比较元素；JS 数组 === 比较身份。这个类比只适用于这里的容器，不能推广到所有类型。Python 方便核对列表内容，JS 数组身份判断适合确认共享；按任务选择，详见差异与边界。
