## Python Logo

`python-logo.svg` 使用 Python 官网提供的蓝黄双蛇标志，保留原始路径、渐变、比例及阴影。仅补充与原始画布等价的 `viewBox`，使网页图标和 favicon 能等比例缩放，没有重绘或改色。

- 官方说明：https://www.python.org/community/logos/
- 官方 SVG 下载链接：https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg
- 商标政策：https://www.python.org/psf/trademarks/
- 获取日期：2026-09-15
