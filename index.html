你熟悉的 TypeScript / Node.js 接下来学习的 Python 需要重新理解的地方
let / const、Array、Map 名字绑定、list、dict 赋值会共享对象；list 和 dict 的 == 比较内容，is 比较身份。
类型注解、interface 类型提示、dataclass、Protocol Python 类型提示也不自动校验输入；定义结构与验证数据是两件事。
import、npm、package.json import、uv、.venv、pyproject.toml 环境、安装工具与项目配置各司其职；虚拟环境不等同于 node_modules。
Promise、async / await 协程、Task、asyncio 调用 async def 得到协程对象，函数体还未开始执行；需要 await 或调度为任务。

THE LEARNING PATH

从语言对照，走到独立交付。

7 个阶段 · 29 节规划课程。按练习表现推进，不预设周数。

  1. 01

    基础语法

    对照 let / const、数组与 Map，学习名字绑定、list / dict、控制流和函数。

    过关证据 · 从空文件写出账单计算器，能解释输出与异常。

  2. 02

    日常 Python 与工程习惯

    从 Node.js 模块、fs 与 npm 出发，理解 import、pathlib、uv、异常和测试。

    过关证据 · 读取脏数据，报告错误，把脚本拆成可测试模块。

  3. 03

    项目一 · 文件清单 CLI

    第一次独立用 Python 完成扫描、统计与导出；按里程碑实现，不提供整套 TS 答案。

    过关证据 · 处理中文路径、权限错误，输出可复核的 JSON 清单。

  4. 04

    进阶语言与数据处理

    对照 TS 的类型与迭代协议，再学 Python 对象模型、生成器、装饰器与资源管理。

    过关证据 · 按行处理大文件，能说明何时需要抽象。

  5. 05

    项目二 · 支出分析报告

    用 Python 处理 CSV、金额与 SQLite，再生成图表和 HTML 报告。

    过关证据 · 对账总额准确，重复导入不重复记账。

  6. 06

    网络、数据库与并发

    从 Promise 和 Node.js 事件循环出发，区分 Python 协程、线程、进程与阻塞 I/O。

    过关证据 · 实现限流、超时与取消，能区分 I/O 密集和 CPU 密集。

  7. 07

    项目三 · 学习书签 API

    用 FastAPI 实现服务与持久化；用熟悉的 TS 客户端验收接口。

    过关证据 · 重启不丢数据，接口可测试，按 README 可复现启动。

HOW TO LEARN

看懂以后，
关掉答案再写一次。

基础课先看 TS / Python 对照，练习时自己写 Python。进入项目后逐步减少对照，用 Python 的标准库和工具独立完成实现。

  1. 回忆：不翻笔记，说出上节课的一个概念。
  2. 对照与预测：先看熟悉的 TS 写法，预测 Python 的结果，再运行验证。
  3. 改写：换一组输入，补一个边界情况。
  4. 独立完成：从空文件实现练习，再看参考答案。
  5. 提交证据：留下代码、命令、输出和仍不理解的问题。
