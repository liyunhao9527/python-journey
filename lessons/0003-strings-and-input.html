2. input 读到的是文本

input() 是读取一行终端输入的 Python 内置函数。它显示提示，等待你输入并按回车，返回字符串 str；末尾换行被移除，两端空格仍保留。使用它后，就能换输入运行脚本，不必每次改源码。

即使键入 25，返回的也是文本 "25"。第二课的 int() 负责把合法整数文本转为整数。

raw_minutes = input("分钟：")
print(type(raw_minutes))
minutes = int(raw_minutes)
print(minutes + 5)

输入 25，类型输出是 <class 'str'>，计算结果为 30。input 不负责数字转换，也不检查业务范围。本课先输入非负整数文本：空行、abc、25.5 传给 int 都会报 ValueError。负整数能转换，但未必符合计时业务；校验在条件与异常课程展开。

官方规则：input 与 int。

3. 清理姓名，格式化摘要

strip() 是字符串的方法，即通过字符串对象调用的操作。它返回去掉两端空白后的结果，用来清理误输入的空格；它不删除中间的空格，也不修改原字符串。

f-string 把表达式的结果放进文本。字符串前加 f，花括号中写表达式。{hours:.2f} 的冒号引出格式规则，.2f 表示按定点格式显示两位小数；它只控制显示，不改变 hours 的值。这适合把分钟换成易读的小时数。

完整示例在 demos/03-strings/main.py：

raw_name = input("姓名：")
raw_minutes = input("分钟：")
name = raw_name.strip()
minutes = int(raw_minutes)
hours = minutes / 60
print(f"{name}，本次学习 {minutes} 分钟（{hours:.2f} 小时）。")

从项目根目录执行：

uv run python demos/03-strings/main.py

输入带两端空格的“ 小林 ”并回车，再输入 25。最后一行为：

小林，本次学习 25 分钟（0.42 小时）。

把分钟改为 30，先预测再运行。随后在脚本末尾临时加 print(hours)，输入 25，观察原数值与两位小数显示的区别。

同一个任务的 TypeScript / Node.js 写法

Node 用 readline 接口读取一行；question 返回 Promise，await 等待输入，close 释放接口。这里借用你熟悉的 Node 写法，不要求在 Python 中学习异步。示例使用 ES 模块，保存为 demos/03-strings/equivalent.mts：

import { createInterface } from "node:readline/promises";
import { stdin, stdout } from "node:process";

const terminal = createInterface({ input: stdin, output: stdout });
const rawName = await terminal.question("姓名：");
const rawMinutes = await terminal.question("分钟：");
terminal.close();
const name = rawName.trim();
const minutes = Number(rawMinutes);
const hours = minutes / 60;
console.log(`${name}，本次学习 ${minutes} 分钟（${hours.toFixed(2)} 小时）。`);

支持原生 TS 类型擦除的 Node 可执行 node demos/03-strings/equivalent.mts；也可沿用已有 TS 工具链。Node 执行不替代 tsc 类型检查。

同目标操作差异与类比边界优势、代价与场景
input / questioninput 在当前线程等待；question 返回 Promise。这里都提供字符串。Python 顺序小脚本简短；Node 便于接入异步流程，但要管理接口生命周期。
strip / trim本例都清理两端空格并返回结果；具体 Unicode 空白集合不完全相同。清理本课姓名无明显优劣，都应保留有意义的内部空格。
int / Numberint("") 报错，Number("") 为 0；int("25.5") 报错，Number("25.5") 为 25.5。TS 的 string 类型不能证明文本是数字。int 直接拒绝非整数文本；Number 支持更多数值形式，计时输入仍要校验。
f-string / 模板字符串此处 .2f 与 toFixed(2) 都生成两位小数文本；不能推断所有舍入边界都一致。Python 在占位符中声明格式，JS 调用方法后插值。本课无明显优劣；显示格式不能消除浮点误差。

4. 用切片取得一段文字

切片是按位置取出一段序列的写法。text[start:stop] 取起点到终点之前的内容，位置从 0 开始；省略 start 表示从开头开始。下面从固定格式标签提取日期，不会修改原文字。

label = "2026-09-15 Python"
print(label[:10])
print(label[11:])
print(label[-1])
const label = "2026-09-15 Python";
console.log(label.slice(0, 10));
console.log(label.slice(11));
console.log(label.at(-1));

两段依次输出 2026-09-15、Python、n。[-1] 是索引，取得最后一个位置的字符；它不是切片。JS 用 at(-1) 表达这个目标。

  • 差异：Python 用方括号和冒号，JS 用 slice 方法；本例都是含起点、不含终点。JS 字符串的 [-1] 不代表最后一个字符。
  • 边界：空字符串的 Python [-1] 报 IndexError，JS at(-1) 返回 undefined；两者切片超过末尾都会截到可用范围。固定位置提取不能代替日期校验。
  • 取舍：Python 切片简短，JS 方法名直白；此任务无明显优劣，标签格式变化时都要调整。

5. 文字长度不等于字节数

Unicode 为文字中的字符等分配编号，称为码点；编码规定如何把文字变成字节。Python str 表示 Unicode 文本，UTF-8 是一种常见编码。区分文本与字节，才能理解为什么中文文件大小不等于文字长度。

Python 的 len(text) 计算码点数，JS 的 length 计算 UTF-16 代码单元数。一个代码单元是 UTF-16 的一个 16 位单位，有些码点需要两个单位。用一个 emoji 观察区别：

text = "A🐍"
print(len(text))
print(text[1])
const text = "A🐍";
console.log(text.length);
console.log(text.slice(1));

Python 输出 2 和 🐍，JS 输出 3 和 🐍。JS 此处取从位置 1 到结尾的整段，避免截断 emoji 的两个代码单元。

  • 差异：Python 按码点计数，JS length 按 UTF-16 单元计数。
  • 边界：两者都不是 UTF-8 字节数，也不保证等于人眼看到的字符数；组合音标与组合 emoji 可能含多个码点。
  • 取舍：Python 对单码点 emoji 的索引直观，显示字符分割仍需更多规则；JS 原生操作便于按代码单元处理，面向用户的计数需额外处理。上一节 ASCII 日期位置在两者中一致。

保存脚本为 UTF-8。本课只理解边界，读写文件时指定编码留到文件课。
