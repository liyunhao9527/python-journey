让程序按记录逐条工作。

用条件选择路径，用循环处理任意多条数据。

本课目标：独立遍历记录、累计分钟数、筛选达标记录，并解释 for 与 while 的适用边界。
1. 先回忆容器2. 条件选择3. for 遍历与累计4. while 与边界5. 独立完成统计本课参考

1. 先回忆容器

第四课把多条记录放进列表，把字段放进字典。现在的问题是：如果记录从两条变成任意多条，怎样避免重复写 records[0]、records[1]？控制流让同一段代码逐条执行。

records = [{"topic": "容器", "minutes": 30}, {"topic": "函数", "minutes": 20}]
print(records[0]["minutes"] + records[1]["minutes"])

先预测输出 50。下一步会把“取一条记录并处理”放进循环。

2. 条件选择

if 只在条件为真时执行缩进代码。elif 继续检查其他条件，else 处理前面都不满足的情况。每个分支的缩进必须一致；这不是排版，而是语法。

minutes = 20
if minutes >= 25:
    label = "完整"
else:
    label = "短练习"
print(label)

这里输出“短练习”。比较运算会产生 True 或 False；if 也会按真值判断空列表、空字符串和 0，但业务代码应明确写出条件。

const minutes = 20;
const label = minutes >= 25 ? "完整" : "短练习";
console.log(label);
同一目标差异与边界取舍与场景
二选一Python 常用多行 if/else；TS 可用三元表达式。两者都按真值选择。短表达式用三元式清楚；分支有副作用或多步操作时，多行结构更易读。
缺失值Python 的 None、JS 的 null/undefined 不是同一个运行时值。不要只靠类型提示代替检查。边界输入先明确规则，再写条件；这样错误会在数据入口暴露。

当 minutes = 20 时，label 是什么？

3. for 遍历与累计

for item in items 从序列中依次取出每一项。循环体每次看到的 record 都是当前字典。累计变量要在循环前初始化。

records = [
    {"topic": "字符串", "minutes": 25},
    {"topic": "容器", "minutes": 30},
    {"topic": "字符串", "minutes": 15},
]
total = 0
long_sessions = []
for index, record in enumerate(records, start=1):
    total += record["minutes"]
    if record["minutes"] >= 25:
        long_sessions.append(record["topic"])
    print(f"第 {index} 条：{record['topic']}（{record['minutes']} 分钟）")
print(f"总计 {total} 分钟")
print(f"达到 25 分钟：{', '.join(long_sessions)}")

核对输出

第 2 条：容器（30 分钟）
第 3 条：字符串（15 分钟）
总计 70 分钟
达到 25 分钟：字符串, 容器

enumerate 同时给出序号和元素；start=1 只改变显示序号，不改变列表索引。range(3) 产生 0、1、2，终点 3 不包含。

let total = 0;
const longSessions: string[] = [];
records.forEach((record, index) => {
  total += record.minutes;
  if (record.minutes >= 25) longSessions.push(record.topic);
  console.log(`第 ${index + 1} 条：${record.topic}`);
});
  • 共同目标：顺序处理数组 / 列表，并维护累计值。
  • 边界：Python for 遍历任意可迭代对象；这里的 TS forEach 回调不能用 break 结束外层遍历。
  • 取舍：需要跳过或提前结束时，Python 可用 continue / break，TS 可用普通 for...of；仅做每项相同处理时，forEach 简洁。

4. while 与边界

while 适合“尚未满足条件就继续”的重复。循环体必须让条件最终改变，否则会无限循环。读取输入直到得到非空主题时，条件比固定次数更自然。

topic = ""
attempts = 0
while not topic:
    topic = input("主题（不能为空）：").strip()
    attempts += 1
print(f"收到：{topic}，尝试 {attempts} 次")

如果用户先输入空白，再输入容器，程序会循环两次。break 立即离开当前循环，continue 跳到下一轮；先用条件表达完整规则，再考虑它们。

循环适合风险
for遍历已有列表、字典或固定次数。修改正在遍历的列表可能跳过元素；先建立结果列表更稳妥。
while直到输入有效、队列为空或状态完成。忘记更新状态会无限循环；可在开发时加尝试次数上限。
