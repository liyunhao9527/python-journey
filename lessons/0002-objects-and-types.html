2. 赋值让名字指向对象

对象是 Python 表示数据的基本单位；变量名是访问对象的名字。对象有类型、值和身份。类型决定支持哪些操作，身份用于区分“同一个对象”与“值相同的另一个对象”。赋值 = 先计算右边，再把左边的名字绑定到结果对象，不会自动复制对象。

整数 int 是不可变对象：整数自身的值不能改。下面的加法计算出 30，再让 minutes 指向结果；previous 仍指向 25。先预测输出，再展开解释。

minutes = 25
previous = minutes
minutes = minutes + 5
print(previous, minutes)

let minutes = 25;
const previous = minutes;
minutes = minutes + 5;
console.log(previous, minutes);
核对预测

两段都输出 25 30。赋值不是建立一个会跟随另一个名字变化的公式。

  • 差异：Python 无需 let / const；JS 的 const 禁止重新绑定，let 允许重新绑定。
  • 类比边界：这里 Python 整数与 JS number 的赋值结果相同，但 JS number 是原始值，不能由此推断两种语言的所有数据模型都一样。
  • 优势与代价：Python 写计时脚本简短，但绑定保护要靠约定或检查工具；TS / JS 用 const 表达不重新绑定的意图，多一个声明选择。本例需要更新 minutes，TS / JS 选 let，保存 previous 选 const。

规则来源：Python 3.14 数据模型。

3. 类型属于对象

type(value) 返回对象的类型，用于确认眼前的数据是什么。下面几种值会出现在计时脚本里；本课采用 Python 3.14。

Python 值与类型同目标 TS 表达差异、边界与选择
25：int，整数分钟25：numberPython int 支持任意精度，受内存限制；JS number 仅在安全整数范围内保证整数精确。本课小整数无明显优劣。
0.5：float，小时比例0.5：number两者通常都用二进制浮点，不能精确表示所有十进制小数。方便算比例，金额精确对账另选方案。
True / False：bool，是否完成true / false：booleanPython 首字母大写。本课都用于表达真假，无明显优劣。
"25"：str，文本分钟"25"：string文本不是数字，计算前需转换；Python str 不可变，JS string 是不可变原始值。
None：NoneType，尚无记录null：显式空值可类比“没有值”；Python 没有独立的 undefined 值。TS 开启 strictNullChecks 时会区分 null 与 number；Python 执行本身不提供这种静态检查。
minutes = 25
print(type(minutes))
minutes = "25"
print(type(minutes))

依次得到 <class 'int'> 和 <class 'str'>。这是名字换了绑定对象。对应的 TS let minutes = 25; minutes = "25"; 会被类型检查器拒绝，因为推断为 number；JS 运行时允许这次赋值。TS 静态检查、Node 执行与 Python 执行要分开看。Python 的灵活性适合短脚本，但同名变量反复换类型会增加阅读成本；本课保持 minutes 为整数。

计算文本分钟时，int("25") 把合法的整数文本转换为整数。"25" + 5 在 Python 中抛出 TypeError；JS 会得到字符串 "255"。Python 的显式转换便于发现类型不匹配，代价是多写转换；JS 拼接方便，但计算时要留意隐式转换。本课输入固定为合法整数文本，无效文本处理留到异常课。

raw_minutes = "25"
minutes = int(raw_minutes)
print(minutes + 5)
print(minutes / 60)
const rawMinutes = "25";
const minutes = Number(rawMinutes);
console.log(minutes + 5);
console.log(minutes / 60);

都先输出 30，再输出约 0.4167。Python 的整数 / 运算返回 float；JS number 除法仍返回 number。这里转换结果相同，但 int 与 Number 并非通用等价转换器：例如 int("") 报错，Number("") 为 0。

4. 修改对象，会影响所有共享它的名字

可变对象允许在原对象上修改内容。列表 list 是按顺序保存元素的容器；[25] 创建一个包含整数 25 的列表，.append(5) 在这个列表末尾添加 5。本课用它保存每次学习的分钟数，不展开其他列表操作。

sessions = [25]
shared = sessions
shared.append(5)
print(sessions, shared)
const sessions = [25];
const shared = sessions;
shared.push(5);
console.log(sessions, shared);
先预测两个列表的内容，再看解释

两个名字看到的内容都是 [25, 5]。它们指向同一个列表：修改 shared 指向的对象，也能通过 sessions 看到。Node 输出数组的空格排版可能不同。

  • 相同点：本例 Python list 和 JS Array 都共享对象；简单赋值不会创建独立容器。
  • 失效边界：const 保护的是绑定，不能阻止 push；Python 整数的重新赋值也不能类比为列表的原地修改。
  • 优势与代价：共享对象省去复制，适合共同维护同一份记录；需要独立修改时容易互相影响。两种语言在本例没有明显优劣，都要明确是否共享。

现在把 shared.append(5) 换成 shared = [5]，先预测再运行。新写法创建另一个列表并重新绑定 shared；sessions 仍为 [25]。TS 对照若做同样重新绑定，需将 shared 的声明改成 let。

5. 相等不等于同一个对象

== 判断相等，is 判断是否为同一个对象。对本课的整数列表，Python == 比较对应元素；我们用两个新建列表区分内容和身份。

a = [25, 5]
b = [25, 5]
c = a
print(a == b)
print(a is b)
print(a is c)
const a = [25, 5];
const b = [25, 5];
const c = a;
console.log(a === b);
console.log(a === c);
  • 差异：Python 输出 True、False、True；JS 输出 false、true。JS 数组的 === 判断身份，不逐项比较。
  • 类比边界：Python is 可类比本例数组的 ===，不能推广到 JS 原始值；Python == 也不是所有对象通用的深度比较算法。
  • 优势与代价：Python 列表内容比较方便核对记录，但可能要逐项检查；JS 数组身份比较适合确认共享，核对内容要另写规则。本课应根据“核对分钟数”或“确认共享”选择判断方式。

判断数字或字符串的值，用 ==，不要用 is。实现可能复用不可变对象，不能用某次整数身份判断的结果推断通用规则。判断“尚无记录”通常写 record is None；None 是单例，即只有一个这样的对象。record = None 后该判断为 True，而 0 表示已记录零分钟，并非缺失。

sessions = [25]；shared = sessions；shared.append(5) 后，sessions 是什么？
